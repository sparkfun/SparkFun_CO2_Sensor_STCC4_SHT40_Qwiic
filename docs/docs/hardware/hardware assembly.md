# Hardware Assembly

Let's go ahead and wire this up in a Qwiic circuit to start getting CO<sub>2</sub>, temperature and humidity data from this breakout.

## Qwiic Assembly

Since this is a Qwiic breakout, all we need to do is plug it into a Qwiic-comaptible development board, like the RedBoard IoT shown below, with a Qwiic cable. After that, plug the RedBoard into a computer over USB-C and we can move on to using the SparkFun STCC4 Arduino library to get data from the sensors:
