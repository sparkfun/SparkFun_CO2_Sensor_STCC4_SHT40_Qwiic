# Introduction

![SparkFun CO2 Sensor - STCC4/SHT40 (Qwiic) Banner Image](/img/Qwiic_STCC4STH40-HGBanner.png)

The [SparkFun CO2 Sensor - STCC4/SHT40 (Qwiic)](https://www.sparkfun.com/sparkfun-co2-sensor-stcc4-sht40-qwiic.html) makes it easy to get highly-accurate, environmentally compensated indoor CO<sub>2</sub> data with no soldering required. This Qwiic breakout features a pair of isolated sensors from Sensirion, the STCC4 CO2 sensor and the SHT40 digital temperature and humidity sensor. These two sensors work together to output precise and environmentally compensated CO2 readings without any complicated wiring.

In order to follow along with this tutorial you'll need the SparkFun CO2 Sensor - STCC4/SHT40 (Qwiic) along with the following items:

* [SparkFun RedBoard IoT - RP2350](https://www.sparkfun.com/catalog/product/view/id/17811/s/sparkfun-iot-redboard-rp2350/) (or other Arduino development board)
* [Qwiic Cable](https://www.sparkfun.com/flexible-qwiic-cable-100mm.html)
* [USB-C Cable](https://www.sparkfun.com/usb-c-to-usb-c-cable-1-meter-flexible-silicone.html)

## Topics Covered

This document contains three main sections: **Quick Start Guide**, **Hardware** and **Software**.

The Quick Start Guide goes over assembling the CO2 Sensor in a Qwiic circuit with a compatible Arduino development board and jumps right into installing and uploading an example from the SparkFun STCC4 Arduino Library to get data from the sensor in just a few minutes.

The Hardware pages include a hardware overview that provides a detailed overview of the CO2 Sensor - STCC4/SHT40 (Qwiic) and all major components on the board. The Hardware Assembly page goes over the steps required to assemble and use the board to measure formaldehyde concentrations with a compatible Arduino development board.

The Software pages give instructions on how to install the SparkFun STCC4 Arduino Library and use some of the examples included in it.
